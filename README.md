# ДиалогПРО 🎯 — ИИ-тренажер сложных переговоров и общения

**ДиалогПРО** — это умный интерактивный веб-тренажер на базе искусственного интеллекта (Google Gemini), предназначенный для безопасной отработки сложных деловых и жизненных разговоров. 

Сервис помогает подготовиться к переговорам с руководством, защите проектов, собеседованиям, жестким продажам, разрешению конфликтов и деликатным межличностным ситуациям.

---

## 🌟 Ключевые возможности

- **🤖 ИИ-оппонент с адаптивным характером**: Симулирует реального оппонента (строгого руководителя, капризного клиента, скептичного партнера или настойчивого продавца) с учетом выбранного уровня сложности и тональности.
- **🎭 Гибкие роли**: Поддержка любых сценариев взаимоотношений (Руководитель ↔ Сотрудник, Продавец ↔ Клиент, Заказчик ↔ Подрядчик, Ментор ↔ Ученик).
- **📊 Профессиональная аналитика (Оценщик)**: После завершения сессии ИИ анализирует диалог, оценивает ключевые навыки (уверенность, аргументация, стрессоустойчивость, работа с возражениями) по 100-балльной шкале.
- **💡 Советы коуча и альтернативные формулировки**: Разбор допущенных ошибок и рекомендации по тому, как можно было сказать эффективнее.
- **📚 Богатая база сценариев**:
  - *Деловые переговоры*: защита бюджета, повышение зарплаты, кризисные кейсы, управление ожиданиями.
  - *Собеседования*: жесткий HR-скрининг, технические интервью, неудобные вопросы.
  - *Личное и бытовое общение*: свидания, границы в отношениях, решение конфликтов.
  - *Деликатные темы*: отработка настойчивых продаж, переговоры с подрядчиками, конфиденциальные вопросы.

## 🛠️ Технологический стек

- **Frontend**: React 18, TypeScript, Tailwind CSS, Lucide Icons.
- **Backend**: Node.js, Express, TypeScript (`server.ts`).
- **AI Engine**: `@google/genai` (Google Gemini API) для генерации реплик оппонента и экспертной оценки сессий.

## 🚀 Быстрый старт

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/your-username/dialog-pro.git
   cd dialog-pro
   ```

2. Установите зависимости:
   ```bash
   npm install
   ```

3. Настройте переменные окружения:
   Создайте файл `.env` на основе `.env.example` и добавьте ваш ключ Gemini API:
   ```env
   GEMINI_API_KEY=your_gemini_api_key_here
   ```

4. Запустите проект в режиме разработки:
   ```bash
   npm run dev
   ```

5. Соберите проект для продакшна:
   ```bash
   npm run build
   ```
