## 💡 Зачем это нужно

Сложный разговор — стресс, а цена ошибки высока. ДиалогПРО даёт безопасную
песочницу: ИИ-оппонент давит, возражает и капризничает как настоящий,
а вы отрабатываете навыки и получаете профессиональный разбор от ИИ-коуча.

## 🔄 Как это работает

1. **Выбираете сценарий** — защита бюджета, повышение зарплаты, жёсткое
   собеседование, конфликт и т.д.
2. **Ведёте диалог** с адаптивным ИИ-оппонентом: строгий руководитель,
   капризный клиент, скептичный партнёр, настойчивый продавец.
3. **Получаете разбор**: оценки навыков по 100-балльной шкале, ошибки
   и альтернативные формулировки от коуча.

## 🌟 Ключевые возможности

- 🤖 **Адаптивный ИИ-оппонент** — характер, тон и уровень сложности
  настраиваются; оппонент реагирует на ваши реплики как живой.
- 🎭 **Гибкие роли** — Руководитель ↔ Сотрудник, Продавец ↔ Клиент,
  Заказчик ↔ Подрядчик, Ментор ↔ Ученик и любые другие связки.
- 📊 **Оценщик сессии** — уверенность, аргументация, стрессоустойчивость,
  работа с возражениями; всё по 100-балльной шкале.
- 💡 **Коуч** — разбор ошибок и рекомендации, как сказать эффективнее.
- 📚 **База сценариев** — деловые переговоры, собеседования, личные
  и деликатные темы.

## 🚀 Быстрый старт

```bash
# 1. Клонируйте репозиторий
git clone https://github.com/your-username/dialog-pro.git
cd dialog-pro

# 2. Установите зависимости
npm install

# 3. Настройте окружение
cp .env.example .env
# впишите в .env ваш ключ: GEMINI_API_KEY=...

# 4. Запустите разработку
npm run dev

# 5. Продакшн-сборка
npm run build
```
